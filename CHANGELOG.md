# CHANGELOG

tools-docs is a website, not a versioned package: it has no releases or tags, and
nothing is published to a registry. Each change lands on `main` through a pull
request and goes live when the Deploy workflow (`cd.yml`) is run, so the merged
pull requests are the record of changes:
<https://github.com/n24q02m/tools-docs/pulls?q=is%3Apr+is%3Amerged>
