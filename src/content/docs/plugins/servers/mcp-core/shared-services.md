:::caution[Archived (2026-10-24)]
`mcp-core` is superseded by [hull](/hull/overview/) (PyPI `n24q02m-hull`, npm `@n24q02m/hull`). Every server in this stack now pins hull, so new work and questions belong there.
:::

This page described `mcp-core`, which no current server uses. Its content has been removed; the URL stays so existing links resolve. See the [mcp-core notice](/plugins/servers/mcp-core/). The shared embedding and reranking HTTP service is now `fastretrieval-server` from `fastretrieval[server]`; see the [Fastretrieval library](/plugins/reference/fastretrieval/).
