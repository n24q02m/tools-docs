:::caution[Archived]
`mcp-core` is archived and no longer maintained; its GitHub repository is read-only. Every server in this stack now builds on [hull](/hull/overview/) (PyPI `n24q02m-hull`, npm `@n24q02m/hull`).
:::

None of the old mcp-core content applies to a current server, so it has been removed; this URL stays so existing links keep working. For how a server takes credentials, which transport it runs, and how HTTP clients authenticate, see that server's setup page under [MCP servers](/plugins/servers/). The upgrade notes for each server are in that server's repository.
