`jules` is a lightweight task runner and execution archiver for long-running workflows, background workers, and autonomous tool sessions.

## Features

- **Task Isolation**: Structured run directories with automatic session lifecycle management.
- **Transcript Provenance**: Deterministic recording of commands, tool calls, and exit statuses.
- **Fail-Closed Execution**: Guardrails against silent swallows of pipeline failures.
