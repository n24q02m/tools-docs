## 2026-09-12 - External icon on internal links
**Learning:** Found that the hero actions on the index page used the 'external' icon for links that actually pointed to internal documentation routes (e.g., /skret/overview/). Using an external link icon for internal navigation breaks user expectations and can be confusing.
**Action:** Always ensure the icon used matches the link destination. Use 'right-arrow' or no icon for internal links, and 'external' only for actual external links.
